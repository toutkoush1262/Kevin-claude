# Mushroom Survivors

A small Vampire Survivors–style game set in a fungal forest. Open `index.html` in a browser; no build step needed.

- **Move:** WASD / arrow keys, or drag on touch screens. **Pause:** P / Esc.
- Spells fire automatically. Collect glowing spores to level up and choose upgrades.
- Enemies: slimes, bats, goblins, walking toadstools, wisps and trolls; they get tougher over time.
- Magic mushrooms: red heals, blue gives a speed boost, gold pulls in every spore.
