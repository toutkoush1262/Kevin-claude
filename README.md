# Mushroom Survivors

A small Vampire Survivors–style game: you are a mushroom, and every hungry creature in the forest wants to eat you. Open `index.html` in a browser; no build step needed.

- **Move:** WASD / arrow keys, or drag on touch screens. **Pause:** P / Esc.
- Spells fire automatically. Collect glowing spores to level up and choose upgrades.
- Hungry enemies: slugs, bats, goblins (with forks), truffle boars, pixies and trolls (with spoons); they get tougher over time.
- Magic mushrooms: red heals, blue gives a speed boost, gold pulls in every spore.
- Skills level up to 15. At skill levels 5, 10 and 15, pick a permanent modifier that changes how the skill behaves (e.g. Mycelium Tendrils: Taproot for one big hit, or Fungal Web for more, weaker splits).
- Enemies drop colored crystals (trolls always do). Every 10 player levels, Old Toadley the crystal merchant appears; walk into him to spend crystals: blue levels an active skill, green a passive skill, purple anything, and red (as rare as purple) takes a level from a skill you pick, then levels a random active skill and a random passive skill.
